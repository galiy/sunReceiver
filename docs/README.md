# Документация sunReceiver

Русскоязычная документация проекта.

- **[Универсальный контракт значений (`values`)](universal-contract.md)** — полное описание
  каждого тега контракта: одинаковые имена и единицы измерения для Deye и Sofar, таблицы
  тегов (общие / только Sofar / только Deye), соотношения к регистрам и масштабам (ratio),
  биты аварий, примечания к согласованию единиц.

## Кратко

sunReceiver опрашивает solar-инверторы (Deye и Sofar) через WiFi-даталоггеры (Solarman V5,
TCP порт 8899) и сохраняет распарсенные данные в JSON. Для кросс-марочного потребления
данные нормализуются в **универсальный контракт** — единый набор тегов `values` с
идентичными именами и единицами измерения для обеих марок. Подробнее — в
[universal-contract.md](universal-contract.md).

Технические детали протокола, поведения логгеров и маппинга регистров — в [`AGENTS.md`](../AGENTS.md).
