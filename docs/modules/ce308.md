# Счётчик Энергомера CE308 (BLE)

Счётчик трёхфазный, опрос по BLE (протокол Энергомера/IEC 61107). Работает
**единственным режимом — только итоговые показания**: пулер не держит постоянное
соединение, не пишет мгновенную телеметрию и не ведёт агрегатов. Раз в 30 минут
(или по кнопке «Обновить» на дашборде) он однократно подключается, снимает
накопленную энергию и отключается.

## Конфигурация

```json
"ce308": {
  "disabled": false,
  "name": "CE308 #000000000",
  "mac": "AA:BB:CC:DD:EE:FF",
  "pin": "CHANGE_ME_PIN"
}
```

| Поле | Описание |
|---|---|
| `disabled` | **обязательно**: `false` — счётчик опрашивается, `true` — отключён |
| `name` | имя устройства (по умолчанию `CE308 <MAC>`) |
| `mac` | BD_ADDR счётчика (BLE) |
| `pin` | BLE-PIN радиоинтерфейса (6 цифр) |

Период фиксирован (30 мин); поля `poll.ce308` и `ce308.final_readings_only` удалены.

## Поток данных

`CE308 → BLE → runCe308FinalReadings → /api/ce308/energy → Redis`

- Накопленная энергия (`EMD01..EMD04`, суточный архив i=0) снимается за одно
  подключение: активная/реактивная × день/ночь × потребление/отдача.
- Хранится один ключ `sunreceiver:ce308-energy:current` (JSON `ce308EnergySnapshot`);
  история по энергии не ведётся.
- Мгновенная телеметрия и ряд `ts:ce308:*` больше не пишутся; таблица PG
  `ce308_averages_r` удалена.
- Ошибки связи пишутся в `device_errors` (kind=`ce308`) по общему правилу.

## API

| Метод | Назначение |
|---|---|
| `GET /api/ce308/energy` | последний снимок накопленной энергии |
| `POST /api/ce308/energy` | сигнал снять показания (не чаще 5 мин, иначе 429) |

`/api/ce308/current` и `/api/ce308/series` удалены.

## Сборка/эксплуатация

- BLE-транспорт — `ce308_client.go`; PIN-агент BlueZ — `ce308_agent_linux.go`.
- Счётчик независим от DDS238 (`meter`) и DTS017M (`dts017m`).
- На проде требуется физический BLE-адаптер (см. историческое
  `ce308-bluetooth/README.md`).
