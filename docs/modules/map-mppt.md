# Модуль МАП Титанатор и MPPT-контроллеры

МАП Титанатор и до 16 параллельных **MPPT-контроллеров** Микроарт (`(C)mART`)
опрашиваются **единственным способом** — через HTTP-API «Малина26» (токен по
паролю + бинарные контракты). Легаси-методы (`rs485` по Modbus и `malina` через
`read_json.php`) удалены.

## Источники данных

- **МАП (`kindMAP`)** — бинарный контракт `MapData` из `/api/map/raw`
  (`malina26.go`: `malina26Source`, `decodeMalina26Map`). Раздел `map` содержит
  `disabled`, `host`, `port`, `password`, `serial`, необязательный `fallback_serial`.
  Ключ устройства в Redis/PG — `"map"` (не зависит от прибора).
- **MPPT-контроллеры (`kindMPPT`)** — из `/api/kes/raw` (`decodeMalina26KES`).
  В `sunReceiver.json` они **не регистрируются**: состав динамический по ответу
  API. Контроллер появляется на дашборде, когда приходит в ответе, и исчезает,
  когда перестаёт отвечать (ключ удаляется из `current` через `PruneMPPT`; чистка —
  только при УСПЕШНОМ ответе API). Имя — `MPPT-<serial>`, ключ — `mppt-<serial>`.

**Резервный серийник МАП.** Если основного `serial` нет в `/api/map/devices`,
ищется `fallback_serial`; опрашивается он, но идентичность (ключи, `device_sn`,
статистика) остаётся по основному `serial`. Пока активен резервный, список
перечитывается раз в 60 с; при 2 подряд неуспехах raw/декодирования основного —
переключение на резервный, возврат — после успешного raw.

**`map.disabled`** (обязательное) — мастер-выключатель раздела: при `true` не
запускаются пулеры МАП, КЭС и BMS26.

## `values` МАП/КЭС (теги в `commonContractTags`)

- **МАП** (`decodeMalina26Map`): `battery_voltage`/`l1_voltage` =
  `UAcc_med_VH/VL` (0x405/0x406), `battery_current` = `(L+H*256)/16` со знаком
  заряд− (`MODE_RAM` 0x400 == 4), `battery_power` = `U×I`, `grid_voltage` =
  `UNET`+100, `grid_power` = `PNET_8/8×100` (знак `PNET_Sign_P`), `grid_frequency`
  = `6250/TFNET`, `map_temp_*` = `Grad0/1/2 − 50` (`Temp_off`-биты).
- **КЭС** (`decodeMalina26KES`, контракт `KESR`): `pv1_*`, `l1_*`,
  `ac_active_power`, `energy_today` = `PwrKW + PwrW/10000`.
- Версии контрактов пиннятся (`MapData version=5/402`, `KESR version=1`), при
  расхождении payload отвергается.

## Ключ устройства и цикл опроса

- **Ключ в Redis/PG = `devKey(t)`**: `kindMPPT` → `mppt-<UID>`; `kindMAP` → `"map"`;
  инверторы — по серийнику.
- **Опрос МАП/КЭС — 1 раз в секунду** (`runMapPoll`), отдельно от 10-секундных
  циклов инверторов. Запись — `saveMapSnapshot`: score = секунда снятия, пишется
  каждое показание; PG усредняет до 1 точки за 5 минут.

## Ошибки МАП

Ошибки читаются **только «сырыми»** из бинарного контракта `MapData`
(`/api/map/raw`, `malina26.mapErrCells`), отдельным циклом ≤1/30 с
(`map_errors.go`). Запись — в `device_errors` (device=`map`, kind=`map`), только
появление ошибки, без дублей. Агрегирующие эндпоинты с готовыми текстами не
используются.

Ячейки-ошибки МАП (RAM, из `protocol_MAP_cells_2026_07_15.doc`):

| Ячейка | Имя | Смысл |
|---|---|---|
| 0x41C | `_F_AccOver` | отключения по перегрузкам АКБ (8 бит) |
| 0x41D | `_F_NETOver` | отключения по перегрузкам сети (биты 0,1,3) |
| 0x42A | `_RSErrSis` | критические системные ошибки |
| 0x42B | `_RSErrJobM` | аварии АКБ/сети/выхода |
| 0x42C | `_RSErrJob` | перегрузки/перегрев/вентилятор |
| 0x42D | `_RSWarning` | рабочие предупреждения |
| 0x447 | `_RSErrDop` | 3-фазные/параллельные/I2C/BMS/MPPT |
