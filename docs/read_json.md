# Веб-интерфейс Микроарт (192.168.13.60) — read_json.php

> Проверено живьём 2026-09-07, текущее время ~21:44.

Сайт МАП Микроарт отдаёт текущие параметры МАП Титанатор, MPPT-контроллеров (КЭС) и АКБ
по HTTP с **Basic-авторизацией** (`admin` / пароль из `malina.json`, файл исключён из git).
Сервер: Microsoft-IIS/6.0, интерфейс на PHP (`index.php`, `read_memory.php`, `read_json.php`,
`write_eeprom.php`).

Учётные данные и все используемые URL хранятся в `malina.json` рядом с исполняемым файлом
(в git не попадает, см. `.gitignore`).

```
read_json.php?device=map
read_json.php?device=mppt
read_json.php?device=bat
```

В `malina.json` эти пути заданы в `site.urls` как `read_json_map` / `read_json_mppt` / `read_json_bat`;
полный URL = `site.base_url` + путь. `read_memory`/`write_eeprom` — там же.

**Важно:** в отличие от Modbus-гейта МАП (порт 502), `read_json.php?device=mppt` отдаёт
**полные индивидуальные параметры каждого MPPT-контроллера** (`Vc_PV`, `Ic_PV`, `V_Bat`,
`P_PV`, `P_Out`, `I_Ch`, `Temp_Int`, `Temp_Bat`, …), которых через гейт МАП получить нельзя
(там только агрегат `_I_Akb_MPPT`/`_Takb_MPPT`/`_UAcc_med`).

| `_E_NET`/`_E_ACC`/`_E_ACC_CHARGE`/`_E_NET_SIGN` | Энергии за текущие сутки (Вт·ч), знак «−» — продажа |
| `_E_*_B` | Суммарные энергетические счётчики (Вт·ч) |

| `_I_acc_3ph`/`_I_ph1..3`, `_P_acc_3ph`/`_P_ph1..3` | Ток/мощность АКБ по фазам (3-фазная модель; на 1-фазной только ф1) |

## `device=mppt` — параметры MPPT-контроллеров (КЭС)

> **Источник данных мониторинга MPPT (`kindMPPT`).** Эндпоинт отдаёт полные параметры
> каждого MPPT-контроллера, которых нет в Modbus-гейте МАП (Vc_PV/Ic_PV/P_PV, V_Bat,
> I_Ch, P_Out). В `sunReceiver.json` каждый контроллер задаётся как `{"type":"mppt",
> "slot": <индекс в массиве>}` (слот = позиция в ответе, 0..N-1). `mpptSite` собирается
> из `malina.json` (`base_url` + `urls.read_json_mppt` + Basic-auth). Время актуальности
> данных — поле `timestamp` ответа (Unix), им же помечается снимок.

Массив из N объектов — по одному на каждый подключённый MPPT-контроллер (в нашей системе — 3:
UID 1097, 1750, 1751, соответствуют MPPT-1/2/3). Поля совпадают с картой памяти МППТ
(`docs/map/mppt/Карта Памяти_MPPT_WG_2021_01_18.xlsx`, лист «Данные для Мониторинга»).

Пример (UID 1097, 21:44:16):

```json
{"timestamp":"1788806656","time":"21:44:16","UID":"1097","Vc_PV":"51.2","Ic_PV":"0.0",
 "V_Bat":"52.1","P_PV":"0","P_Out":"0","P_Load":"0","P_curr":"0","I_Ch":"0.0","I_Out":"0.0",
 "Temp_Int":"26","Temp_Bat":"25","Pwr_kW":"4.097","Sign_C0":"0","Sign_C1":"0","I_EXTS0":"0",
 "I_EXTS1":"0","P_EXTS0":"0","P_EXTS1":"0","Relay_C":"0","RSErrSis":"0","Mode":"B",
 "Sign":"+","MPP":"L","windspeed":"65535","FW":"8.7","R1":"0","R2":"0","R3":"0"}
```

| Поле | Описание |
|---|---|
| `timestamp` / `time` | Unix-сек. / локальное время |
| `UID` | Серийный номер контроллера (адрес в вебе) |
| `Vc_PV` | Напряжение солнечных панелей, В (RAW 0x2D9) |
| `Ic_PV` | Ток солнечных панелей, А (RAW 0x2DF) |
| `V_Bat` | Напряжение АКБ (входная), В (RAW 0x2E5) |
| `P_PV` | Мощность солнечных панелей, Вт (RAW 0x2EB) |
| `P_Out` | Мощность на выходе контроллера, Вт (RAW 0x2ED, `P_MPPT`) |
| `P_Load` | Мощность нагрузки, Вт (RAW 0x2F5, = `P_EXTS[1]`) |
| `P_curr` | Мощность заряда, Вт (RAW 0x2F9) |
| `I_Ch` | Ток заряда АКБ, А (RAW 0x2FB) |
| `I_Out` | Ток на выходе контроллера, А (RAW 0x2FF) |
| `Temp_Int` | Внутренняя температура, °C (RAW 0x31D) |
| `Temp_Bat` | Температура АКБ, °C (RAW 0x31E) |
| `Pwr_kW` / `Pwr_W` | Энергия за сутки, кВт·ч / Вт (RAW 0x3A1 / 0x39F); суммарно за сутки = `Pwr_kW*1000+Pwr_W`; в контракт идёт как `energy_today` = `Pwr_kW + Pwr_W/1000` кВт·ч |
| `Sign_C0`/`Sign_C1` | Знак тока датчиков №1/№2 («+»=0, «−»=1) (RAW 0x404/0x405) |
| `I_EXTS0`/`I_EXTS1` | Ток через датчики №1/№2; №2 = ток нагрузки (RAW 0x406/0x408) |
| `P_EXTS0`/`P_EXTS1` | Мощность от альт. источника / мощность нагрузки (RAW 0x40A/0x40C) |
| `Relay_C` | Состояния реле (RAW 0x3E3) |
| `RSErrSis` | Ошибки контроллера (RAW 0x3B6) |
| `Mode` | Текущий режим (B = буферный заряд?), символьный |
| `Sign` | Знак мощности, '+'/'-' |
| `MPP` | Состояние точки максим. мощности (L = load?) |
| `windspeed` | Скорость ветра (65535 = нет ветряка) |
| `FW` | Версия ПО контроллера (8.7) |
| `R1`/`R2`/`R3` | Состояния реле 1..3 |

**Значения в ночной период (21:44) логичны:** Vc_PV ≈ 51.2 В (панели под напряжением, но ток
0.0 А), V_Bat ≈ 52 В (сошлось с `_Uacc` МАП), P_PV / P_Out / P_curr = 0 (нет инсоляции,
буферный режим). `Mode:"B"`, `MPP:"L"`, `RSErrSis:0` — ошибок нет.

> Примечание: в карте памяти МППТ для чтения через «Монитор» к адресам RAM добавляется 0x1F0
> (напр. `Vc_PV` 0x2D9 → 0x4C9). Здесь веб-интерфейс уже отдаёт значения, готовые к отображению.

## `device=bat` — параметры АКБ

Массив из двух объектов: расчётные параметры банки/батареи и производные величины.

Пример (21:43:55 / 21:44:17):

```json
[{"timestamp":"1788806635","time":"21:43:55","C20":"400.0","C20_t":"398.4","Uacc_avg":"52.10",
  "Iavg":"-4.26","C_Ah_remain":"107.0","C_100_remain":"0.7","C(I)":"457.9","TTG":"4925",
  "mppt_day_E":"11360","low_V":"51.2","hi_V":"56.8","cycles":"0","LD":"0.0","DD":"0.7",
  "AD":"0.7","Esum_from_bat":"16102","Esum_to_bat":"11065","No_async":"28","est_soc":"-1.0",
  "cons_Ah":"-291.4","E_wind_day":"0"},
 {"timestamp":"1788806657","time":"21:44:17","dCdt":"-0.0011","dEdt":"0.0560","Isumm":"-3.875",
  "IntegralC_0_t":"-0.0247","Integral_E_0_t":"1.2864","t_bat":"23","Ah_user":"420.4",
  "Wh_user":"1017449","Sun_I":"0.0","Sun_P":"0","wind_I":"0.0","wind_P":"0"}]
```

Объект 1 — расчёт АКБ:

| Поле | Описание |
|---|---|
| `C20` / `C20_t` | Ёмкость по 20-ч разряду, А·ч (номинал / с учётом температуры) |
| `Uacc_avg` | Среднее напряжение АКБ, В |
| `Iavg` | Средний ток АКБ, А (− = заряд идет в банку?) |
| `C_Ah_remain` | Оставшаяся ёмкость, А·ч |
| `C_100_remain` | Оставшаяся ёмкость относительно C20, % |
| `C(I)` | Ёмкость с учётом тока (эффект Пейкерта), А·ч |
| `TTG` | Время до генерации в сек. |
| `mppt_day_E` | Энергия от MPPT за сутки, Вт·ч |
| `low_V` / `hi_V` | Мин./макс. напряжение АКБ (56.8 = буферное) |
| `cycles` | Число циклов |
| `LD` = load?, `DD` = deep discharge?, `AD` = accepted? | Степени разряда/нагрузки (доли) |
| `Esum_from_bat` / `Esum_to_bat` | Суммарная энергия из/в АКБ за сутки, Вт·ч |
| `No_async` | Число асинхронныx (событий?) |
| `est_soc` | Оценка SoC, % (−1 = нет данных) |
| `cons_Ah` | Потреблённые А·ч за расчётный период (− = нетто-заряд) |
| `E_wind_day` | Энергия от ветряка за сутки, Вт·ч |

Объект 2 — производные параметры:

| Поле | Описание |
|---|---|
| `dCdt` / `dEdt` | Скорость изменения ёмкости/энергии во времени |
| `Isumm` | Суммарный ток |
| `IntegralC_0_t` / `Integral_E_0_t` | Интеграл тока / энергии от 0 до t |
| `t_bat` | Температура АКБ, °C (≈ `Temp_Bat` mppt) |
| `Ah_user` | Пользовательская ёмкость АКБ, А·ч |
| `Wh_user` | Энергетическая ёмкость по паспорту, Вт·ч |
| `Sun_I`/`Sun_P`, `wind_I`/`wind_P` | Ток/мощность солнца и ветра |

## Авторизация

Без авторизации возвращается `401/403` (Basic realm «Restricted»). Работает Basic Auth
`admin` / пароль из `malina.json`. Пример запроса:

```
curl -u "admin:$(jq -r .site.auth.password malina.json)" \
     "http://192.168.13.60/read_json.php?device=mppt"
```
