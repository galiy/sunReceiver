## Выполнено

### 1. Не заносить в историю ошибки инверторов `no_data` — сделано (2026-10-01)

- `runInverterPoll`: при `code == "no_data"` запись в `device_errors` не делается
  (остаются heartbeat-коды и fault-регистры).
- История очищена на проде: `DELETE FROM sunreceiver.device_errors WHERE
  kind='inverter' AND code='no_data'` → удалено 340 записей.


### 2. EnBMS: warn-область Battery — сделано (2026-10-01/02)

- Реверс APK (`parseBody_Battery` 0x3f3a18 + `toJson` 0x3def6c): хвост Battery
  (39 Б) = warn-область (0..23: 16 байт по ячейкам + 4 по температурам + env/power/
  charge warn) + статусы (24..38). Первая гипотеза (`Ext_Bit` XML `teleSignal_Group`)
  давала ложные аварии — отвергнута.
- `parseEnBmsTail` читает только warn-область (на здоровом кадре пусто; проверено).
- Имена warn-битов ячейки — `enbmsCellWarnBits` (из APK).
- `enbmsAlarmHistory=true` (сработает при опросе). **Опрос EnBMS выключен
  пользователем — не включать.**
- Сырой лог `enbms: RAW …` (hex хвоста) включён в коде, при выключенном опросе не
  пишется.
- Подробности: `energybms/PROTOCOL.md` §5.1.1–5.1.2, `REVERSE_ENGINEERING.md` §2.1.

### 3. Deye: аварии — сделано (2026-10-02)

- Fault-карта: R103–R106 = `0x67–0x6A` (UINT64, LSW-first), бит N−1 = F(N).
  Подтверждено живым событием (сеть off): `0x69.2` → **F35 AC_NoUtility**,
  `status(0x3B)`: 2→4→1→2.
- Предупреждения: `0x65/0x66` (32 бита), бит N−1 = W(N) → `deyeWarnNames` (W1–W32).
- `decodeDeyeFaults` → появления в `device_errors` (kind=`inverter`); предупреждения —
  только в сыром логе. Локализация ru/en/zh; тесты (`deye_faults_test.go`).
- Источник карт: `pbix/HA-solark-PV` + сохранённая страница Inversol (W1–W32/F1–F64).
- Docs: `docs/research/deye-registers.md`.
