# map-settings — отдельная программа управления настройками МАП

Самостоятельное приложение (не часть sunReceiver) для **чтения, инспекции и
редактирования ячеек МАП** (Титанатор / Доминатор) через веб-UI.
Чтение и запись — по **Modbus TCP** к `mapgateway` (порт 502 на ПАК «Малина»).

Запускается на этом ПК из каталога `mapsettings/`; встраивается в один бинарник
(UI и каталог ячеек через `go:embed`), внешних зависимостей нет (только stdlib).

## Сборка и запуск

```sh
cd /home/sasha/src/sunReceiver/mapsettings
go build -o mapsettings .        # сборка
./mapsettings                    # запуск (по умолчанию :8099, МАП 192.168.13.60:502)
```

Флаги:

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `-listen` | `:8099` | адрес HTTP-сервера |
| `-map` | `192.168.13.60:502` | адрес `mapgateway` (host:port) — значение по умолчанию для UI |
| `-unit` | `1` | Modbus-адрес МАП |
| `-user` / `-pass` | пусто | HTTP Basic для `/api/*` (пусто — без авторизации) |
| `-version` | | показать версию и выйти |

Открыть в браузере: `http://127.0.0.1:8099/`.

### Локальный конфиг

Настройки (модель, IP, порт) сохраняются браузером (localStorage) и, кроме того,
сервер записывает их в **`mapsettings.json`** рядом с бинарником — значения
восстанавливаются при следующем запуске. Флаги переопределяют конфиг.
Файл **не коммитится** (в `.gitignore`), как и сам бинарник.

```sh
go test ./...    # тесты (валидация каталога, разбор значений)
go vet ./...
```

## Возможности

- **Кнопки «Перечитать» и «Записать».** «Перечитать» снимает полный снимок;
  «Записать» отправляет **только изменённые** пользователем параметры.
- **Все параметры с русскими именами и по логическим блокам.**
- **Служебное обрамление записи** (как делает `mapd`):
  `03 (ComMAP_EEPromWR) → запись → 07 (ComMAP_Call_load_EEProm)` + чтение-обратно.
- **Два режима**: Титанатор и Доминатор (от режима зависит набор параметров).
  Режим, IP и порт сохраняются на клиенте (localStorage) и восстанавливаются.
- **Отдельный раздел «Управляющие воздействия и мониторинг»**: команды МАП
  (`ComMAP_ON/OFF/ChargeON/ChargeOFF/StatReset/DischOff/load/Reset`) и все
  не‑настроечные (ro) параметры — состояния, сеть, АКБ, выход, счётчики, служебное.
- **Отдельная форма «Текущее время»** — чтение и запись ячеек времени
  `0x1B6`/`0x44B`.
- **Кнопка «?» у каждого параметра и органа управления** — подсказка из
  документации (описание, единица/формула, расшифровка значений и битов).

## API

| Метод и путь | Назначение |
|---|---|
| `GET /api/config` | значения по умолчанию (режим/IP/порт/unit) |
| `GET /api/settings?mode=&ip=&port=` | снимок: `settings` (rw) + `monitor` (ro) + `actions` |
| `POST /api/apply` | `{mode,ip,port,changes:{key:value}}` — запись только изменённых |
| `POST /api/action` | `{mode,ip,port,key}` — управляющее воздействие |
| `GET /api/time?...` / `POST /api/time` | чтение/запись времени МАП |

## Каталог ячеек

Источник — **единственный актуальный документ**
`docs/map/map/protocol_MAP_cells_2026_07_15.doc` (Malina web API как эталон
не используется). `catalog.json` (227 параметров) сгенерирован скриптом
`catalog_gen.py` и встроен в бинарник.

```sh
python3 catalog_gen.py            # перегенерировать catalog.json из документа
```

Требуется `libreoffice` (скрипт сам конвертирует `.doc`); каталог детерминирован
и проходит самопроверки (русские имена, корректные `width`/`order` парных байт,
уникальные ключи).

## Безопасность

- Записываются только параметры с `access=rw`; служебная область `0x000..0x004`
  защищена от записи настройкой.
- Перед записью — служебное разрешение (команда `03`), после — фиксация (`07`) и
  чтение-обратно (верификация); расхождение попадает в результат.
- Опасные действия (включение/выключение, сброс, запрет разряда) требуют
  подтверждения в UI.

## Структура

| Файл | Назначение |
|---|---|
| `main.go` | флаги, разбор адреса, запуск HTTP-сервера |
| `config.go` | локальный конфиг `mapsettings.json` (загрузка/сохранение) |
| `server.go` | HTTP API и отдача UI (embed `web/`) |
| `catalog.go` | каталог, чтение снимка, дельта-запись, действия, время |
| `modbus_client.go` / `modbus_write.go` | Modbus TCP: чтение 0x03, запись 0x06/0x10, команды |
| `catalog.json` / `catalog_gen.py` | каталог ячеек и его генератор |
| `web/` | `index.html`, `app.css`, `app.js` |
| `catalog_test.go` | тесты каталога и разбора значений |
